# Reverse Engineering Notes: Attendly (attendly-xi.vercel.app)

## 1. Executive Summary & Target Architecture

- **Target Website**: [https://attendly-xi.vercel.app/](https://attendly-xi.vercel.app/)
- **Application Nature**: A mobile-first Progressive Web App (PWA) / Single Page Application serving as a student academic companion and attendance tracker for students using the **SchoolPad** ERP system.
- **Underlying Technology Stack**:
  - **Framework**: React Native for Web (`react-native-web`) with **Expo Router** (`globalThis.__EXPO_ROUTER_HYDRATE__ = true`).
  - **Styling**: Tailwind CSS / NativeWind (`tailwind.css` v3.3.2) augmented by React Native stylesheet primitives (`r-*` classes).
  - **Typography**: `Lexend` font family (`Lexend_400Regular`, `Lexend_500Medium`, `Lexend_600SemiBold`, `Lexend_700Bold`, `Lexend_800ExtraBold`).
  - **Desktop Experience**: On viewport widths $\ge$ 768px, the application renders a realistic mobile phone viewport inside a centered container (`width: 430px`, `height: calc(100vh - 60px)`, `border-radius: 20px`, drop-shadow) over a deep gradient background (`linear-gradient(135deg, #1a1a2e 0%, #16213e 50%, #0f0f23 100%)`) with a top banner `"📱 Use your mobile phone for a better experience"`. On mobile viewports (< 768px), it occupies 100% full screen.
  - **Backend Integration**: Integrates with SchoolPad API endpoints (`https://gdemo.schoolpad.in/mobile/getClientDetails`, `mobilev2/appLoginAuthV2`, etc.) with default school code `800002`, combined with a complete **Demo Mode** with rich static student data for Alex Johnson.

## 3. Identification of the Previous Execution Error

- **Exact Failing Operation**:
  In step 46, a PowerShell command was executed to inspect the JSON artifact outputs generated by REA Playwright captures:
  ```powershell
  powershell -Command "$json = Get-Content '...output.txt' -Raw; $obj = $json | ConvertFrom-Json; Write-Output $obj.normalized_result.steps[-1].artifacts.accessibility.value.text..."
  ```
- **Error Output**:
  ```text
  = : The term '=' is not recognized as the name of a cmdlet, function, script file, or operable program.
  At line:1 char:2
  +  = Get-Content 'C:\Users\visha\...
  ```
- **Root Cause Analysis**:
  The command string passed to `powershell -Command` was wrapped in double quotes. The outer shell evaluated `$json` and `$obj` before launching the PowerShell subshell, resulting in empty variable substitutions and the invalid statement `= Get-Content...`. Subsequently, API rate-limiting (HTTP 429) interrupted the agent before recovery.
- **Correction Applied**:
  The underlying REA Playwright capture in Step 43 had actually succeeded and contained all requested accessibility and DOM data (`step.artifacts.dom.value.text` and `step.artifacts.accessibility.value.text`). The accessibility data was successfully extracted via Node.js parsing and corroborated directly against the decompiled bundle and screenshots.
